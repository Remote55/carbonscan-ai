# แก้ภาษาบนเว็บให้เป็นภาษาคน — Design

> **วันที่:** 31 ก.ค. 2569 · **กำหนดส่ง:** อาจารย์ฟัง present จันทร์ 3 ส.ค. · แข่ง 5 ส.ค.

## ที่มา

อาจารย์ที่ปรึกษาอ่านหน้าเว็บแล้วตอบกลับมาตามนี้

> "อจ.อ่านแล้วมันเป็นภาษา GenAI เหมือนเรายังไม่ได้แก้อะไรเลยอ่ะค่ะ เดี๋ยววันจันทร์
> present ให้ฟังหน่อยนะคะ ว่าต้องการจะสื่ออะไรในแต่ละหัวข้อที่ใส่มาค่ะ"

พร้อมยกตัวอย่างประโยคจากหน้าเว็บสองประโยค แล้วถามต่อว่า

> "อะไรที่ freeze และบอกข้อจำกัดได้ทุกขั้นเลยหรอคะ"

คำถามข้อหลังจับได้ว่าเว็บ**เขียนเกินจริง** — เราไม่ได้บอกข้อจำกัดทุกขั้น เรามีข้อจำกัด
ของชุดทดสอบ 3 ชุด และมีหลายขั้นที่ยังไม่ได้ทดสอบเลย

การไล่โค้ดยืนยันว่าคำวิจารณ์ถูกต้อง มีข้อความที่ไม่ควรอยู่บนหน้าเว็บจริง

| ข้อความที่พบ | มันคืออะไร |
|---|---|
| "หนึ่ง narrative ต่อเนื่อง…แทนการแยก feature เป็นการ์ดที่ดูมีน้ำหนักเท่ากัน" | เหตุผลการจัดเลย์เอาต์ ไม่ได้บอกวิธีวัดสักคำ |
| "Measured evidence / do not round" | คำสั่งถึงคนเขียนโค้ด หลุดไปแสดงให้ผู้ใช้เห็น |
| "Field observation / 01" | ป้ายตกแต่ง ไม่มีความหมาย |

## หลักการเดียวที่ใช้ตัดสินทุกประโยค

> ถ้าประโยคอธิบายว่า **"เราออกแบบแบบนี้เพราะ…"** → ลบ
> ถ้าประโยคตอบ **คำถามที่คนอ่านสงสัยจริง** → เก็บ แล้วเขียนใหม่เป็นภาษาคน

ผลพลอยได้ที่ตั้งใจ: ประโยคเดียวที่บอกว่าแต่ละหัวข้อมีไว้ตอบอะไร **คือบทพูดวันจันทร์**

## แนวทางที่เลือก

เลือก **แก้ข้อความ + เปลี่ยนหัวข้อเป็นคำถาม + ซ่อนศัพท์ไว้ใต้ปุ่มกาง**

ที่ไม่เลือก: แยกหน้า `/evidence` ออกมาต่างหาก — ต้องเพิ่ม route, เทสต์ และ browser
journey ใหม่ ใช้เวลาเกิน 2 วัน และกินเวลาซ้อมก่อนแข่ง

เหตุผลที่หัวข้อต้องเป็นคำถาม: หัวข้อชื่อ **"วัดยังไง"** เขียนเป็นเหตุผลการออกแบบไม่ได้
มันเขียนได้อย่างเดียวคือวิธีวัด โครงสร้างบังคับให้เนื้อหาตรงประเด็นเอง

### เชื่อได้แค่ไหน

ประโยคนำ

> เราทดสอบไป 3 ชุด แต่ละชุดบอกได้แค่บางเรื่อง **และมีขั้นที่ยังไม่ได้ทดสอบเลย**

**ทดสอบแล้ว**
- แยกลำต้น–ใบ — แต่ใช้ชุดเดียวกันตอนเลือกรอบเทรนที่ดีที่สุด ค่าจึงเข้าข้างตัวเอง

**ยังไม่ได้ทดสอบ**
- ระบบทั้งเส้นตั้งแต่รับไฟล์จนได้ค่าคาร์บอน
- สมการชีวมวลกับข้อมูลต้นไม้จริงในไทย
- การแยกชนิดพันธุ์ — ยังเป็นโครงเปล่า

## Component ใหม่ — `TechnicalDetail`


แปลว่าต้องดูแล `aria-expanded` และ focus เองโดยไม่ได้อะไรเพิ่ม

## กับดักฟอนต์ — ต้องแก้ก่อน ไม่งั้นหัวข้อไทยจะพัง

`.editorial-eyebrow` ใน `globals.css` ปัจจุบันคือ

```css
@apply font-mono text-[0.6875rem] font-medium uppercase tracking-[0.16em] text-canopy;
```

หัวข้อ eyebrow ทั้งหมดกำลังจะเปลี่ยนเป็นภาษาไทย ซึ่งชนกับคลาสนี้สามทาง

1. **`font-mono` = JetBrains Mono ไม่มีสระไทย** ตัวอักษรไทยจะตกไปใช้ฟอนต์สำรองที่ขนาด 11px
   โปรเจกต์นี้เคยโดนบั๊กนี้มาแล้วที่ `evidence-metric.tsx` และมีคนทักว่า "ตัวมันเล็ก อ่านไม่ออก"
2. `uppercase` ไม่มีผลกับภาษาไทย
3. `tracking-[0.16em]` ทำให้สระกับวรรณยุกต์ลอยห่างจากพยัญชนะ

**ทางแก้:** เพิ่มคลาสคู่ `.editorial-eyebrow-th` — sans, ไม่ uppercase, tracking น้อยลง
คลาสเดิมคงไว้สำหรับป้ายที่ยังเป็นอังกฤษ เช่นบรรทัด `TreeQ Carbon / NSC 2026 / Deep Tech`

3. การแยกชนิดพันธุ์ **ยังเป็นโครงเปล่า**
4. โหมด frozen ต้องขึ้น **NOT A LIVE RUN**
5. ตัวเลข Wood IoU / Leaf IoU / DBH MAE ต้องแสดงเต็ม **ไม่ปัดเศษ**

## นอกขอบเขต

- ไม่เปลี่ยนสี ฟอนต์ เลย์เอาต์ หรือรูป
- ไม่เพิ่ม route ใหม่
- ไม่แตะ API, ML pipeline, launcher
- ไม่แก้เอกสารใน `docs/` (ยกเว้นไฟล์นี้)

## ความเสี่ยง

| ความเสี่ยง | รับมือ |
|---|---|
| แก้ข้อความแล้วเผลอลบคำเตือนความจริงทิ้ง | รายการ "สิ่งที่ห้ามหายไป" 5 ข้อ ตรวจทีละข้อก่อน merge |
| browser journey แดงเพราะข้อความเปลี่ยน | ตั้งใจให้แดง แล้วแก้เทสต์ให้ตรงข้อความใหม่โดยไม่ลดความเข้ม |
| เหลือ 2 วันก่อน present และ 5 วันก่อนแข่ง | ขอบเขตจำกัดที่ข้อความล้วน ไม่แตะ logic · ถ้าไม่ทันให้ตัดหน้า `/demo` ออกก่อน หน้าแรกสำคัญกว่า |
| แก้เสร็จแล้วยังอ่านเหมือน GenAI อยู่ | ทดสอบด้วยคน — ให้เพื่อนที่ไม่ได้เขียนโค้ดอ่านแล้วเล่าว่าแต่ละหัวข้อบอกอะไร ถ้าเล่าไม่ได้ แปลว่ายังไม่ผ่าน |

## เสร็จแล้ววัดยังไงว่าสำเร็จ

1. คนที่ไม่ได้อยู่ในโปรเจกต์อ่านหน้าแรกจบ แล้วเล่าได้ว่าแต่ละหัวข้อบอกอะไร
2. ตอบคำถามอาจารย์ได้ว่า "อะไรที่ freeze" และ "ข้อจำกัดครอบคลุมแค่ไหน" โดยหน้าเว็บ
   ไม่เขียนเกินจริงอีก
3. gate เดิมเขียวครบ — web unit, browser journey, type-check, lint, build
