# ส่วนที่ 1 — โปรเจคนี้คืออะไร (อ่าน 5 นาที)

## เรื่องย่อในสามประโยค

1. ต้นไม้ดูดคาร์บอนไว้ในตัวมัน ถ้าจะขาย "คาร์บอนเครดิต" ต้องมีคนไปวัดต้นไม้ก่อนว่ามีคาร์บอนเท่าไหร่
2. ทุกวันนี้ต้องส่งคนเดินเข้าป่าไปวัดทีละต้น ใช้เวลาเป็นวัน ค่าจ้างหลักแสนต่อแปลง
3. **TreeQ รับภาพสามมิติของป่าเข้ามา แล้วให้คอมพิวเตอร์วัดให้** — เร็วกว่า ถูกกว่า และตรวจย้อนได้

## สิ่งที่ทำให้โปรเจคนี้ต่างจากคนอื่น

โปรเจคส่วนใหญ่จะโชว์ว่า "ระบบเราแม่น 95%"

**TreeQ โชว์ว่าตัวเองวัดอะไรไม่ได้**

จากต้นไม้ 5 ต้นในตัวอย่าง ระบบวัดสำเร็จ 3 ต้น **อีก 2 ต้นวัดไม่ได้ และระบบบอกออกมาตรงๆ ว่าต้นไหนและเพราะอะไร**

> **ทำไมสำคัญ:** ถ้าเป็นการซื้อขายคาร์บอนจริง แล้วรายงานแค่ 3 ต้นที่สำเร็จ
> เท่ากับรายงานเกินความจริงไปกว่า 40% — คนซื้อจ่ายเงินให้คาร์บอนที่ไม่มีอยู่

**นี่คือแกนของการนำเสนอทั้งหมด** ถ้าจำได้แค่เรื่องเดียว จำเรื่องนี้

## ระบบทำงานกี่ขั้น — พูด 4 เท่านั้น

**บนจอเขียนไว้ 4 ขั้น ให้พูดตามจอ** อย่าพูด 6 เพราะกรรมการจะมองหาขั้นที่ 5 กับ 6 บนจอแล้วไม่เจอ

| ขั้นบนจอ | ทำอะไร | เปรียบเทียบง่ายๆ |
|---|---|---|
| 1 | รับภาพสามมิติของต้นไม้ | ได้กลุ่มจุดที่หมุนดูได้ |
| 2 | **แยกลำต้นออกจากใบ** | ← ขั้นที่สำคัญที่สุด |
| 3 | วัดขนาดต้นไม้ | เส้นรอบวง ความสูง ปริมาตรเนื้อไม้ |
| 4 | คำนวณคาร์บอน | ใช้สมการมาตรฐานสากล |

**ทำไมขั้น 2 สำคัญ:** ใบไม้ไม่ใช่เนื้อไม้ ถ้าเอาจุดที่เป็นใบไปคำนวณขนาดลำต้นด้วย ตัวเลขจะบวมเกินจริงทันที

**ถ้ากรรมการถามลึกกว่านี้** ข้างในขั้นที่ 1–3 มีขั้นย่อยอีก 6 ขั้น (แยกพื้นดิน → ปรับความสูงจากพื้นจริง →
ทำแผนที่ยอดไม้ → แยกว่าจุดไหนของต้นไหน → แยกเนื้อไม้กับใบ → วัดขนาด) **ไม่ต้องท่อง** ตอบว่า
*"ในทางเทคนิคมีขั้นย่อยอีกครับ อยู่ในรายงาน"* แล้วกดปุ่ม **รายละเอียดทางเทคนิค** บนจอให้ดู

## 🎯 การ์ดซ้อม — หัวข้อบนเว็บ 4 ข้อ

หน้าเว็บมีหัวข้อใหญ่ 4 อัน **แต่ละอันเป็นคำถาม** เลื่อนถึงหัวข้อไหน พูดคำตอบของหัวข้อนั้น
ไม่ต้องจำลำดับอะไรเพิ่ม เพราะจอบอกอยู่แล้วว่าตอนนี้อยู่ตรงไหน

**ซ้อมอันนี้ให้พูดได้โดยไม่ต้องดูกระดาษ แล้วที่เหลือจะง่ายหมด**

| หัวข้อบนจอ | พูดประมาณนี้ (~20 วินาทีต่อข้อ) |
|---|---|
| **ทำไมต้องวัดใหม่** | "ทุกวันนี้จะรู้ว่าต้นไม้เก็บคาร์บอนเท่าไร ต้องส่งคนเดินเข้าไปวัดทีละต้นครับ ใช้เวลาเป็นวัน และพอได้ตัวเลขมาแล้ว ก็ย้อนไม่ได้ว่ามาจากต้นไหน วัดด้วยวิธีอะไร" |
| **วัดยังไง** | "เราให้คอมพิวเตอร์วัดจากภาพสามมิติครับ มี 4 ขั้น รับไฟล์เข้ามา → แยกลำต้นออกจากใบ → วัดขนาด → คำนวณคาร์บอน ขั้นที่สำคัญที่สุดคือขั้นที่สอง เพราะใบไม่ใช่เนื้อไม้ ถ้าแยกไม่ออกตัวเลขจะบวม" |
| **ขอดูของจริง** | "ไม่ต้องเชื่อผมครับ หมุนดูได้เลย จุดสีน้ำตาลคือส่วนที่ระบบตัดสินว่าเป็นเนื้อไม้ สีเขียวคือใบ ถ้าอาจารย์ไม่เห็นด้วยกับที่มันแบ่ง จะเห็นตั้งแต่ตรงนี้ ก่อนไปดูตัวเลขด้วยซ้ำ" |
| **เชื่อได้แค่ไหน** | "เราทดสอบไป 3 ชุดครับ แต่ละชุดบอกได้แค่บางเรื่อง **และมีขั้นที่เรายังไม่ได้ทดสอบเลย** เขียนไว้บนหน้านี้หมดแล้วครับ" |

### ข้อที่ 4 คือข้อที่จะได้ใจกรรมการ

โปรเจกต์อื่นจะพูดว่าระบบตัวเองแม่นแค่ไหน **เราพูดว่าเรายังไม่ได้ทดสอบอะไรบ้าง**

บนจอแยกให้เห็นสองกล่อง — **ทดสอบแล้ว** กับ **ยังไม่ได้ทดสอบ** ชี้ที่กล่องสีแดงแล้วพูดว่า

> "อันนี้คือสิ่งที่เรายังไม่ได้ทดสอบครับ เราเขียนไว้เอง ไม่ได้รอให้ใครมาจับได้"

**ห้ามพูดว่า "เราบอกข้อจำกัดทุกขั้น"** — ไม่จริง และเป็นประโยคที่อาจารย์ที่ปรึกษาจับได้มาแล้ว
เราแก้บนเว็บไปแล้ว อย่าพูดกลับเข้ามาเอง

### ปุ่ม "รายละเอียดทางเทคนิค"

ทุกขั้นบนจอมีปุ่มนี้ ปิดไว้อยู่ **เปิดเมื่อถูกถามเท่านั้น** อย่าเปิดเอง

ข้างในมีศัพท์อย่าง `tlsep`, `PointNet++`, `Wood IoU` ถ้าเปิดเองแล้วอ่านออกมา
จะกลายเป็นการอ่านศัพท์ที่ตัวเองไม่เข้าใจให้กรรมการฟัง ซึ่งเห็นออกทันที

**ถูก:** กรรมการถาม → กดเปิด → "อยู่ตรงนี้ครับ" → ให้เขาอ่านเอง

## สิ่งที่ระบบยัง **ทำไม่ได้** (ต้องรู้ ไม่งั้นจะเผลอเคลมเกิน)

| ยังทำไม่ได้ | แปลว่า |
|---|---|
| ยังไม่รู้ว่าเป็นต้นไม้ชนิดอะไร | ใช้สมการกลางสำหรับป่าเขตร้อน ไม่ใช่สมการเฉพาะพันธุ์ |
| ยังไม่ได้วัดความแม่นกับป่าจริงในไทย | ทดสอบกับชุดข้อมูลเปิดที่มีค่าอ้างอิงเท่านั้น |
| **ไม่ใช่คาร์บอนเครดิตที่รับรองแล้ว** | เป็นค่าประมาณ · การรับรองต้องผ่าน TGO |

# ส่วนที่ 2 — ศัพท์ 8 คำ (อ่าน 5 นาที)

**ถ้ากรรมการถามคำไหน ให้ตอบตามช่องขวา** ไม่ต้องอธิบายเกินนี้

| คำ | อ่านว่า | ถ้าถูกถาม ให้พูดว่า |
|---|---|---|
| **Point cloud** | พอยท์-คลาวด์ | "กลุ่มจุดสามมิติหลายล้านจุดที่แทนรูปทรงของป่าครับ ได้จาก LiDAR หรือถ่ายภาพหลายมุมแล้วประกอบเป็นสามมิติ" |
| **DBH** | ดี-บี-เอช | "เส้นผ่านศูนย์กลางลำต้นที่ระดับอก ประมาณ 1.3 เมตรจากพื้น เป็นค่ามาตรฐานที่วงการป่าไม้ใช้กันครับ" |
| **Allometric** | แอล-โล-เมท-ริก | "สมการที่แปลงขนาดต้นไม้เป็นน้ำหนักชีวมวลครับ ไม่ได้คิดเอง ใช้สมการ Chave 2014 ที่เป็นมาตรฐานสากล" |
| **ชีวมวล / Biomass** | ไบ-โอ-แมส | "น้ำหนักเนื้อไม้ทั้งต้นครับ พอได้น้ำหนักแล้วคูณสัดส่วนคาร์บอน 0.47 ตาม IPCC ก็ได้คาร์บอน" |
| **tlsep** | ที-แอล-เซป | "วิธีแยกเนื้อไม้ออกจากใบที่เราใช้จริงครับ ใช้หลักเรขาคณิต ดูรูปทรงของกลุ่มจุด **ไม่ใช่ AI**" |
| **PointNet++** | พอยท์-เน็ต-พลัส-พลัส | "โมเดล Deep Learning สำหรับ point cloud ครับ เราเทรนไว้แล้ว **แต่ยังไม่ได้เอามาใช้จริง** — เดี๋ยวผมเล่าเหตุผล" |
| **Frozen Evidence** | โฟรเซน-เอฟ-วิ-เดนซ์ | "ชุดหลักฐานที่ตรึงไว้แล้วตรวจแฮชได้ครับ ทำซ้ำได้ผลเดิมทุกครั้ง" |
| **CO₂e** | ซี-โอ-ทู-อี | "คาร์บอนไดออกไซด์เทียบเท่าครับ คือคาร์บอนคูณ 44 ส่วน 12" |

> ⚠️ **`tlsep` ไม่ใช่ AI** — ข้อนี้พลาดบ่อยที่สุด ถ้าพูดว่า "AI แยกเนื้อไม้ให้" คือ**ผิด**
> และเป็นการเคลมเกินซึ่งกรรมการจับได้ทันทีถ้าเขาอ่านรายงาน

# ส่วนที่ 8 — คำถามที่มีโอกาสโดนสูงสุด (ท่องให้ได้)

**Q: ผมอัปโหลดไฟล์เดียวกับที่หน้าหลักฐาน แต่ได้คาร์บอนไม่เท่ากัน ระบบไม่นิ่งหรือเปล่า**

| | สมการที่ใช้ | คาร์บอน |
|---|---|---|
| หน้าหลักฐาน | สมการเฉพาะของไม้สัก | **1,289.74** |
| อัปโหลดสด | สมการกลางป่าเขตร้อน | **1,146.46** |

> "ดีมากครับที่สังเกตเห็น — คำตอบคือ **ระบบนิ่งครับ แต่สองรอบนั้นตอบคนละคำถาม**
>
> ถ้าดูค่าที่วัดได้จริง คือขนาดและความสูงรายต้น — **ตรงกันทุกตัวเลข ทุกทศนิยม**
>
> ที่ต่างคือขั้นแปลงจากขนาดเป็นน้ำหนัก ชุดหลักฐานนั้นเราระบุไว้ว่าเป็นแปลงไม้สัก
> จึงใช้สมการเฉพาะของไม้สัก ส่วนตอนอัปโหลดสด ระบบ**ไม่รู้ว่าเป็นไม้อะไร**
> จึงใช้สมการกลางสำหรับป่าเขตร้อน
>
> ต่างกัน 11 เปอร์เซ็นต์ครับ — และ **11 เปอร์เซ็นต์นั้นคือเหตุผลที่การจำแนกชนิดพันธุ์
> เป็นงานลำดับถัดไปของเรา** มันไม่ใช่ฟีเจอร์เสริม มันคือตัวที่กำหนดว่าตัวเลขจะแม่นแค่ไหน"

> 💡 **ถ้าอัปโหลดไฟล์เดียวกับหน้าหลักฐาน ให้พูดดักไว้ก่อนเลย** ตอนผลออก:
> "ตัวเลขคาร์บอนตรงนี้จะไม่เท่ากับหน้าหลักฐานนะครับ เพราะหน้านั้นรู้ว่าเป็นไม้สัก
> ส่วนตอนอัปโหลดสดระบบไม่รู้ชนิดพันธุ์ — ค่าที่วัดได้เท่ากันทุกตัว ต่างที่สมการแปลง"
>
> **พูดเองดีกว่าโดนถาม** ถ้าพูดเองจะดูว่าเข้าใจระบบลึก ถ้าโดนจับจะกลายเป็นข้อกล่าวหา
