## 0. TL;DR — เก็บครั้งเดียว ใช้ 3 เป้าหมาย

ลงพื้นที่ **1 ครั้ง** เก็บ **5–10 ต้น** → ป้อนได้ทั้ง:

| ข้อมูลที่เก็บ | ใช้กับ | ได้อะไร |
|---|---|---|
| DBH + ความสูง (วัดมือ) | **G1** | parity plot ไม้ไทย (`fig16`) — "validated on real Thai trees" |
| Point cloud (ภาพถ่าย→3D) | **G1 + G2 + G3** | input ให้ pipeline ทำนาย → เทียบกับที่วัดมือ |
| Manual label ใบ/ลำต้น 2–3 ต้น | **G2** | IoU จริงบนไม้จริง (ปัจจุบันมีแค่ synthetic 0.98) |
| ชนิด + GPS | ทุกเป้า | เลือกสมการ allometric + provenance |

## 1. อุปกรณ์ (Equipment) — งบประหยัด

| อุปกรณ์ | ใช้ทำอะไร | ราคา / แหล่ง |
|---|---|---|
| **สายวัด (tape measure)** ≥ 2 ม. | วัดเส้นรอบวงลำต้น (→ DBH) | ~50–100 บาท ร้านเครื่องเขียน/ฮาร์ดแวร์ |
| **สมาร์ตโฟน** (กล้อง + GPS) | ถ่ายภาพ photogrammetry + พิกัด | มีอยู่แล้ว |
| **Clinometer app** (ฟรี) | วัดความสูงต้นไม้ | "Arboreal Tree Height" / "Measure Height" / "Smart Measure" |
| **ตลับเมตร/เชือก** ~10–20 ม. | วัดระยะยืน (สำหรับ trig ความสูง) | ~50 บาท |
| **ชอล์ก / เทปสี** | มาร์คระดับ 1.3 ม. | ~20 บาท |
| **สมุด / มือถือ (กรอก CSV)** | บันทึกข้อมูล | — |
| 🎁 **(โบนัส) TLS scanner** | point cloud ความแม่นสูงกว่ามาก | **ยืมจากคณะ/อาจารย์ที่ปรึกษา** ถ้าได้ = อัปเกรดผลใหญ่ |

> งบรวมอุปกรณ์ ~150–250 บาท (อยู่ในงบ field ~1,200 บาทแล้ว ที่เหลือเป็นค่าเดินทาง)

## 2. เลือกพื้นที่ + ต้นไม้ (Site & Tree Selection)

**พื้นที่ (เลือกที่เข้าถึงง่าย งบเดินทางต่ำ):**
- ในมหาวิทยาลัย / วัด / สวนสาธารณะ / สวนป่าที่รู้จัก / ติดต่อผ่านอาจารย์ที่ปรึกษา
- พื้นค่อนข้างราบ (วัดความสูงง่าย), ใต้ต้นไม่รก (เห็นลำต้นที่ 1.3 ม.)

**ต้นไม้ (5–10 ต้น):**
- ✅ เน้นชนิดใน scope: **สัก (Tectona grandis), ยางนา (Dipterocarpus alatus)** — รองลงมา ยางพารา, มะค่าโมง
- ✅ เลือก **ขนาดหลากหลาย** (DBH เล็ก–ใหญ่ ~15–60 ซม.) → parity plot มีช่วงกว้าง น่าเชื่อถือ
- ✅ ลำต้นตรง เห็นชัดที่ระดับอก ไม่มีพูพอน/กิ่งที่ 1.3 ม.
- ✅ ยืนเดี่ยวๆ หรือไม่รกเกินไป → photogrammetry ง่ายกว่าป่าทึบ

## 3. ขั้นตอนเก็บข้อมูล "ต่อ 1 ต้น" (Per-Tree Protocol)

ทำ 5 อย่างนี้ทุกต้น:

### 3.1 วัด DBH (เส้นผ่านศูนย์กลางที่ระดับอก 1.3 ม.) 🎯
1. มาร์คระดับ **1.3 ม.** จากโคน (ด้านที่สูงกว่าถ้าอยู่บนเนิน)
2. วัด **เส้นรอบวง (circumference)** ด้วยสายวัด — โอบรอบลำต้นให้สายแนบ ตั้งฉากกับแกนลำต้น (ไม่เฉียง)
3. บันทึก `circumference_cm` → ระบบหาร π ให้เอง **หรือ** ถ้ามีคาลิปเปอร์วัด diameter ตรงๆ ใส่ `dbh_cm`
4. ⚠️ หลีกเลี่ยง: ปุ่ม/พูพอน/แผล ที่ 1.3 ม. (ถ้ามี ขยับขึ้น/ลงเล็กน้อยแล้วจดไว้)

### 3.2 วัดความสูง (Total Height) 🎯
1. เปิด clinometer app
2. ยืนห่างจากต้น **ระยะที่เห็นยอดชัด** (วัดระยะด้วยเชือก/ตลับเมตร — app บางตัวใช้ระยะนี้)
3. เล็งไป **ยอดต้น** + **โคนต้น** → app คำนวณความสูงด้วยตรีโกณ
4. วัด **2–3 ครั้ง** เฉลี่ย, บันทึก `height_m`
5. ⚠️ ยืนบนพื้นราบระดับเดียวกับโคน, เห็นทั้งยอดและโคน

### 3.3 ระบุชนิด (Species)
- บันทึก `species_sci` (ชื่อวิทยาศาสตร์): สัก = `Tectona grandis`, ยางนา = `Dipterocarpus alatus`, ยางพารา = `Hevea brasiliensis`, มะค่าโมง = `Afzelia xylocarpa`
- ถ้าไม่แน่ใจ ถ่ายรูปใบ/เปลือก/ผล ไว้ระบุภายหลัง

### 3.4 พิกัด GPS
- เปิด GPS มือถือ → จดพิกัดที่โคนต้น (ทศนิยม ~6 ตำแหน่ง) — ใช้ทำ provenance/anti-fraud demo

### 3.5 สแกน 3D ด้วย Photogrammetry 📸 (สำคัญสุด — ดูข้อ 4)
- ถ่าย **30–50 รูป** เดินรอบต้น → ได้ point cloud `.ply`
- ตั้งชื่อไฟล์ให้ตรงกับ `point_cloud_file` ใน CSV (เช่น `T01.ply`)

## 4. Photogrammetry Capture Protocol 📸 (คุณภาพรูป = คุณภาพ point cloud)

นี่คือจุดที่พลาดบ่อยสุด — ทำตามนี้เป๊ะ:

| หลักการ | วิธี |
|---|---|
| **เดินรอบ 360°** | เดินเป็นวงรอบต้น ถ่ายทุก ~10–15° (รอบละ ~24–36 รูป) |
| **หลายระดับความสูง** | รอบล่าง (เล็งตรง), รอบกลาง (เงยขึ้น), เก็บยอด — 2–3 ชั้น |
| **overlap 60–80%** | รูปติดกันต้องเหลื่อมกันมาก (อย่าถ่ายห่างกระโดด) |
| **แสงสม่ำเสมอ** | วันเมฆครึ้มดีสุด; เลี่ยงแดดจัด/ย้อนแสง/เงาแข็ง |
| **ไม่มีลม** | ใบ/กิ่งขยับ = photogrammetry พัง — เลือกวันลมสงบ |
| **ต้นเต็มเฟรม** | ให้เห็นต้นทั้งต้น + พื้น/ฉากรอบนิดหน่อย (ช่วย scale) |
| **โฟกัสคม นิ่ง** | อย่าเบลอ; กดโฟกัสก่อนถ่าย |

**ประมวลผลเป็น 3D** (ทำที่บ้าน/Colab): COLMAP → OpenMVS → `.ply`
(หรือถ้ายืม TLS ได้ → ได้ `.las/.laz` ข้ามขั้นนี้ + แม่นกว่ามาก)

## 7. ข้อควรระวัง (Common Mistakes)

- ❌ ถ่ายรูปห่างกันเกินไป (overlap น้อย) → 3D ไม่ติด → ถ่ายถี่ๆ เหลื่อมกันมาก
- ❌ วันลมแรง / ใบไหว → photogrammetry ใบพัง
- ❌ วัด DBH เฉียง หรือไม่ใช่ที่ 1.3 ม. → DBH ผิด
- ❌ เก็บแค่ต้นใหญ่หมด → parity plot ไม่มีช่วง → เลือกขนาดหลากหลาย
- ⚠️ **ความซื่อสัตย์:** photogrammetry มือถือ **แม่นน้อยกว่า TLS** — รายงาน error ตามจริง, เฟรมเป็น "smallholder path" (primary คือ LiDAR upload) ถ้ายืม TLS ได้ให้ใช้แทน
