## Typography Hierarchy

### Display (Hero, big headings)
- **Font:** Space Grotesk Bold
- **Use:** Landing page hero, section titles
- **Why:** เด่น, technical feel, modern

### Body (UI text)
- **Font (Thai):** Sarabun
- **Font (English):** Inter
- **Use:** Buttons, body, labels
- **Why:** อ่านง่าย, ไม่ล้าตา, professional

### Monospace (Code, numbers)
- **Font:** JetBrains Mono
- **Use:** GPS coordinates, code snippets, log
- **Why:** เป็นทางการสำหรับข้อมูลเชิงตัวเลข

## Imagery Style

### Photography
- Natural light, no heavy filters
- ทิวทัศน์ป่า/ต้นไม้จริง (ไม่ stock generic)
- Color grading: slight green tint, lifted blacks
- Subjects: เกษตรกรไทย, ป่าไม้ไทย, drone shots

### Illustrations
- **Flat illustration** + minimal gradient
- Color: brand palette only
- Style: geometric, clean lines
- Inspiration: Stripe, Linear, Vercel docs

### 3D Renders
- Point cloud visualization
- Soft lighting (HDRI environment)
- Brand colors บน wood/leaf segmentation

❌ **Avoid:**
- Cliche eco imagery (เด็กถือต้นไม้, รูปโลกในมือ)
- Over-saturated greens
- Cartoon style
- Heavy 3D rendering (looks unprofessional)

## Brand Voice & Tone

### Voice (Always)
- **Confident** ไม่ tentative
- **Clear** ไม่ jargon (ยกเว้นกับ technical audience)
- **Warm** ไม่ corporate

### Tone (Context-dependent)

| Audience | Tone Example |
|---|---|
| **Marketing/Landing** | Inspiring, vision-focused — "เปลี่ยนต้นไม้เป็นรายได้ ด้วย AI ที่โปร่งใส" |
| **Community user** | Friendly, simple — "สแกนต้นไม้ของคุณวันนี้ ใช้เวลาแค่ 5 นาที" |
| **Industrial user** | Professional — "Verified Carbon Credits with audit-grade transparency" |
| **Error message** | Empathetic — "เราหาต้นไม้ไม่เจอ ลองสแกนใหม่ได้นะ" |
| **Success message** | Celebratory but understated — "บันทึกเรียบร้อย — ต้นไม้ของคุณเก็บคาร์บอน 137 kg/ปี" |

### Words to use
- ต้นไม้, ป่าไม้, ชุมชน, ความโปร่งใส, ตรวจสอบได้, ยั่งยืน

### Words to avoid
- "ฟอกเขียว" (เป็น label ลบ — ใช้กับ "ป้องกัน Greenwashing" แทน)
- "ปฏิวัติ" (over-promise)
- "สุดยอด/เทพ" (slang)

## Logo Variations

| Variation | When to use |
|---|---|
| **Full color horizontal** | Default (Web header) |
| **Full color stacked** | Square contexts (social avatar) |
| **Monochrome (forest)** | Light bg, single color |
| **Monochrome (white)** | Dark bg, reverse |
| **Mark only** | Favicon, small contexts |

Minimum sizes:
- Full logo: 80px width
- Mark only: 24px

Clear space: 0.5× logo height ทุกด้าน
