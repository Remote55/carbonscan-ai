# Forest Observatory visual assets

All four production photographs were newly generated for TreeQ Carbon Platform on
2026-07-29 with OpenAI's built-in image generation tool. No input or reference
images were provided to the generator. The final PNG outputs were center-cropped
only as needed and exported with Chrome Canvas to 1920 × 1080 WebP at quality
0.82. Each asset is recorded in `VISUAL_ASSETS` with the rights value
`generated`.

The rights basis is original, project-directed generation: these files were
created specifically for the TreeQ team and are not copies of third-party
photographs. The supplied Wallhaven and Dribbble references are not production
assets, were not copied into this repository, and were not used as generator
inputs.
