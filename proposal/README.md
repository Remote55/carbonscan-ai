## NSC Proposal Sections (Standard Template)

ส่วนที่บังคับใน Proposal NSC 2026 (หมวด 14):

1. **ข้อมูลโครงการ** (Project Info)
   - ชื่อโครงการ (ภาษาไทย/อังกฤษ)
   - หมวดการแข่งขัน (14)
   - ระดับ (อุดมศึกษา)
   - ทีม + อาจารย์ที่ปรึกษา + สถาบัน

2. **บทคัดย่อ** (Abstract) — 200-300 คำ

3. **หลักการและเหตุผล** (Background & Rationale) — 1-2 หน้า

4. **วัตถุประสงค์** (Objectives) — list bullet points

5. **ขอบเขตของโครงการ** (Scope)
   - In-scope (จะทำ)
   - Out-of-scope (ไม่ทำ — ป้องกัน scope creep)

6. **วิธีดำเนินการ** (Methodology)
   - Technical approach
   - Tech stack
   - Architecture diagram

7. **แผนการดำเนินงาน** (Timeline & Milestones) — Gantt chart

8. **ผลที่คาดว่าจะได้รับ** (Expected Outcomes)

9. **งบประมาณ** (Budget) — ตามที่ NSC sponsor

10. **เอกสารอ้างอิง** (References)

11. **ภาคผนวก** (Appendix)
    - CVs ของทีม + อาจารย์
    - Letter of recommendation (ถ้ามี)
